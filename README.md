  # Anti-AI Qwen Academy | Russian Language EGE-2026 🇷📚

![License](https://img.shields.io/badge/license-MIT-green)
![Language](https://img.shields.io/badge/lang-RU%20%7C%20EN-blue)

A comprehensive, free, and offline educational tool designed to help students prepare for the **Russian Unified State Exam (EGE) in Russian Language 2026**. 

This project is part of the **Anti-AI Qwen Academy** initiative, focusing on critical thinking, verification of facts, and independent logic building rather than blind copying from AI sources.

## ✨ Key Features

*   **Bilingual Interface (RU/EN):** Switch seamlessly between Russian and English using the button in the top-right corner. All questions, explanations, grammar rules, and UI elements are fully translated.
*   **Official Open Variant Basis:** The content is verified against the official open variant of EGE-2026.
*   **Complete Exam Simulation:**
    *   **27 Tasks:** Covers all 26 Part 1 tasks (orthography, syntax, speech norms) and Task 27 (Essay).
    *   **Interactive Trainer:** Multiple-choice questions with **randomized option shuffling** to prevent guessing patterns.
    *   **Instant Feedback:** Correct answers appear only after submission, accompanied by detailed theoretical explanations referencing specific grammar rules.
*   **Essay Criteria Deep Dive:** Dedicated sections explaining criteria K1–K10 (Content, Commentary, Argumentation, Logic, Ethics, Composition, Literacy) with examples of common mistakes.
*   **Exam Timer:** Built-in countdown timer with presets:
    *   **Russian Language EGE:** 210 minutes (3 hours 30 minutes).
    *   **Practice Mode:** 60 minutes.
    *   Visual warnings when time is running low (<5 mins) and critical (<1 min).
*   **Preparation Tools:**
    *   **Checklist:** Interactive progress tracker for key topics (roots, prefixes, suffixes, punctuation, paronyms).
    *   **25-Day Study Plan:** Structured roadmap for Grade 11 students covering orthography, syntax, and essay writing skills.
    *   **Grammar Rules Cards:** Quick reference cards for complex topics like participial phrases, homogeneous members, and indirect speech.

## 🚀 How to Use

1.  **Download:** Click the green `Code` button > `Download ZIP`.
2.  **Extract:** Unzip the file on your computer.
3.  **Run:** Open the `index.html` file in any modern web browser (Chrome, Firefox, Edge, Safari).
4.  **No Installation Needed:** The app runs entirely client-side. No server, no database, no internet connection required.

## 📂 Project Structure

*   `index.html`: The single-file application containing HTML, CSS, and JavaScript.
*   `favicon.ico`: Optional icon for browser tabs.

## 🛡️ Privacy & Security

*   **Zero Tracking:** No analytics, cookies, or data collection.
*   **Local Storage Only:** Progress (answers, checklist state) is saved temporarily in your browser's local storage and resets upon page reload unless configured otherwise.
*   **Open Source:** Code is available for inspection and contribution.
